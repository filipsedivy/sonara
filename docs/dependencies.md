# Dependencies and licences

Versions are pinned in `Cargo.lock` (Rust), `pnpm-lock.yaml` (the desktop frontend) and
`scripts/native/build-codecs.sh` (the codec libraries). `cargo deny check` enforces the licence
allow-list in `deny.toml`: no GPL, AGPL or LGPL crates; MPL-2.0 only unmodified, by owner
decision (LIC-01). This inventory was verified on 2026-10-21 and updated on 2026-10-24.

## Rust workspace

The SFZ sampler (ADR 0010) and the AI Chat (ADR 0011) added no dependency. Sample libraries are user-installed data, not
dependencies, and none is shipped.

**Not used:** `dirs` and `directories` for `sonara-app`'s application directories: `dirs-sys`
0.5 pulls in `option-ext` (MPL-2.0, an owner decision under LIC-01), and both answer differently
from the prototype on Windows (known-folder API instead of `%APPDATA%`) and Linux (a relative
`XDG_DATA_HOME` is ignored); `etcetera` 0.11 differs in the same places.
`sonara-app/src/paths.rs` implements the prototype's three environment lookups instead
(QG-13). Tauri itself uses `dirs` 7.0, so `option-ext` is in the desktop's tree, as an unmodified MPL-2.0 exception.

**Not used:** `tauri-plugin-window-state` for the main window's place and size. It stores them
in the platform's application config folder, which ignores `SONARA_HOME`, and cannot hold the
pane sizes, so `sonara-app/src/window_layout.rs` writes `<config>/window.json` (QG-13).

**Not used:** `interprocess` (considered for IPC). The protocol's transports are a Unix
domain socket and, on Windows, TCP on `127.0.0.1`; `std::os::unix::net` and `std::net` are
exactly those, while `interprocess`'s local sockets are named pipes on Windows (QG-13).

**Not used:** `memmap2` (considered for the decode cache). Every mapping call is
`unsafe`, which RT-10 confines to three modules, so the cache reader uses positional reads.

## Redistribution obligations (for packaged builds)

- **LGPL components** (libsoxr and LAME) must stay dynamically linked and replaceable. A packaged app must ship their licence texts, provide or offer
  their source, and not prohibit reverse engineering for debugging the modifications.
- **The MP3 encoder** is LAME, loaded at run time from
  `Contents/Frameworks/libmp3lame.0.dylib`. MP3 patents have
  expired worldwide, but the LGPL obligations above still apply.
- **Statically linked BSD codecs** of the Rust application: libopus (through `opusic-sys`),
  libvorbis and libogg (through `vorbis_rs`). Their BSD-3-Clause notices must be reproduced
  in the app's licence documentation. cargo-about finds them in the crates (`opusic-sys`'s
  `LICENSE` and the libopus headers, `aotuv_lancer_vorbis_sys`'s and `ogg_next_sys`'s
  `COPYING`), so they are in `rust-crates.txt`.
- **The app bundle** carries all of this in
  `Sonara.app/Contents/Resources/licenses/`, staged by
  `apps/sonara-desktop/scripts/stage-licenses.mjs` into `target/licenses`:
  `THIRD-PARTY-LICENSES.txt` (every file below, joined; About Sonara shows it),
  `NOTICE-LGPL.txt` (libsoxr and LAME: separate and replaceable, their source archives with
  their SHA-256, LAME's one-line export-list change, where the bundled source is and how to
  rebuild from it, how to replace a library without signing the app again, and the permission
  to reverse engineer for debugging), `NOTICE-MPL.txt` (the MPL-2.0
  crates, unmodified, split into those compiled in and those used only while building, with
  their crates.io and repository links, and `lightningcss`), `rust-crates.txt` (cargo-about),
  `frontend.txt` (the production npm packages, from `scripts/check-licenses.mjs --notices`),
  `miniaudio-LICENSE.txt`, and the codec texts that `scripts/native/build-codecs.sh` copies:
  `libsoxr-LICENCE.txt`, `libsoxr-COPYING.LGPL.txt`, `libsoxr-pffft-LICENSE.txt` (the FFTPACK
  licence of the PFFFT code in libsoxr's cr32s engine, which libsoxr's `LICENCE` points to),
  `lame-COPYING.txt`, `lame-LICENSE.txt` and `libFLAC-COPYING.Xiph.txt`.
- **The LGPL sources are bundled** (owner decision of 2026-10-23, instead of a written offer):
  `Contents/Resources/licenses/sources/` holds the source archives of libsoxr and LAME that
  `build-codecs.sh` pins, `lame-3.100-export-list.patch` and `build-codecs.sh` itself, the
  complete corresponding source of the shipped libraries (LGPL 2.1 §6). `stage-licenses.mjs`
  copies the archives from `target/native/downloads/` after checking their SHA-256, and
  `scripts/bundle-macos.sh` checks them again in the app and in the DMG. They add about 1.6 MB
  to the bundle. libFLAC's source is not bundled, because its licence is BSD.
- **The FLAC encoder** is libFLAC 1.4.3 (BSD-3-Clause), loaded at run time from
  `Contents/Frameworks/libFLAC.12.dylib`. Its `COPYING.Xiph` notice must be reproduced in the
  app's licence documentation (`scripts/native/build-codecs.sh` copies it to
  `target/native/licenses/libFLAC-COPYING.Xiph.txt`).
- **Claude Code and Codex CLI** are not bundled and not linked. The AI Chat starts the user's own
  installation; nothing of either is redistributed.
- **FFmpeg** is not bundled. If a future package bundles it, the build's configuration
  (`--enable-gpl` or not) decides whether GPL obligations apply. Check that before bundling.
- **The Sonara licence** is not decided yet (see `LICENSE`). Every dependency above is
  compatible with permissive, proprietary and copyleft choices as long as the LGPL rules are
  followed. JUCE, Tracktion and Pedalboard were rejected because they would force AGPL/GPL.
