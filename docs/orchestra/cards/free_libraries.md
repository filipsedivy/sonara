**How to read this file.** This group covers libraries and sound sources, not instruments, so each section
below is a library card with a fixed field table instead of the instrument JSON card; the coverage matrix
at the end maps the libraries onto Sonara instrument ids. Two judgements recur in every card:

- **Sonara sampler, as is.** Sonara reads only `.sfz` patches and plays the opcode subset listed in
  `sfz.rs` (`sample`, key/velocity ranges, `lorand`/`hirand`, `seq_*`, `sw_*`, `trigger`, `group`/`off_by`,
  loops, `offset`/`end`, `tune`/`transpose`, `volume`, `ampeg_attack`/`ampeg_release`, `#define`/`#include`/
  `default_path`); "every other opcode is recorded … and has no effect" [Cited S55]. Consequence: a region
  that a library gates with `locc`/`hicc` (pedal-down resonance, CC-switched layers) is not silenced but
  plays like any other region [Estimate: inferred from the "no effect" rule in sfz.rs; not tested with a
  library]. Every `trigger` value other than `release` is mapped to an attack trigger [Cited S55]. Structural
  parser limits can silence or stack whole patches even when every opcode is supported: the key-switch range
  and default are read once at the end of the file (Q1); `#include` is read only at the start of a line
  (Q2), without `$define` expansion in its path (Q3), and a nested one resolves against the including file's
  folder (Q4); a `<control>` header clears the enclosing `<global>` (Q11) [Cited S60]. SF2/SF3,
  Kontakt, Decent Sampler (`.dspreset`), Hauptwerk and GrandOrgue (`.organ`) are not played [Cited S55:
  ADR 0010 names SF2 as not played; the scanner looks for `.sfz` files only]. Non-PCM samples (FLAC, Ogg)
  are opened through `AudioStream::open`; a FLAC file sniffs as `Family::Other`, which goes to
  `open_symphonia`, and symphonia is built with its `flac` feature [Cited S55: `sfz.rs` `sample()`, `container.rs`,
  `stream.rs`, `sonara-media/Cargo.toml`]; this path was not exercised with a FLAC library in this session [Estimate:
  no library was loaded].
- **Bundling.** ADR 0010 decision 3: "Libraries are installed by the user; none is bundled" [Cited S55].
  The cards therefore say what the licence alone would allow, and the ADR answer is always no. The rule that
  CC BY-NC and share-alike content is never bundled comes from this research brief, not from the ADR text,
  which says only that none is bundled [Cited S55]; cards cite it as the brief's rule.

| Sonara plays as is? | Partly. The key-switch files do not switch as written: each `<global>` holds `sw_*` and one `sw_last`, then includes an articulation file, and an included file that contains a `<control>` header clears that `<global>`, so its articulation sounds on every note; when the last include has one, the switch range is lost and the remaining articulations never sound (Q11) [Cited S60]. In `1st Violins KS` sustain, legato, marcato and harmonics sound together on every note and the other four never sound; in `Flutes KS` the two re-read includes (sustain looped, staccato) also contain `<control>`, so those two articulations sound on every note [Cited S60]; most other Sonatina key-switch files stack articulations the same way [Estimate: S60 relays a first reading; those files were not re-read]. Notation sustains use `fil_type`, `cutoff`, `fil_veltrack` and a vibrato include, all ignored [Cited S4, S55]; Performance files use `gain_cc1`/`set_cc1`, ignored [Cited S4, S55]. ## Open questions and disagreements between sources

1. **VCSL README vs tree.** The README says VCSL "shall include the bulk of the VSCO 2 CE sample set" [Cited
   S2], but the `master` tree has no bowed strings, brass or orchestral woodwinds [Cited S2: tree]. Use VSCO 2 CE
   for the orchestra and VCSL for keyboards and percussion.
2. **Correction to Sonara's research doc.** `orchestral-audio-engine-research.md` §5 says FreePats' "harp is CC
   BY-NC" [Cited S55]; the FreePats harp page states CC0 1.0 for the sounds and CC BY-NC only for the photo
   [Cited S10]. Recommend correcting the doc. The same doc's "bass" in VSCO 2 CE is a solo contrabass, not a
   section [Cited S1].
3. **Keppy's Steinway licence.** CC BY 4.0 (5.1-6.27) and CC BY-SA 4.0 (7.x) per the mirror README; CC BY-SA 4.0
   in the mirror's `LICENSE.md`; CC0 on the mirror's project page; `by-sa` for 5.2 on Musical Artifacts [Cited
   S44, S45]. Recommend the strictest reading (BY-SA): user install only.
4. **Kawai upright.** MuseScore handbook: GPL v3+ with exception, 58 MB uncompressed [Cited S36]; current FreePats
   page: CC0 1.0 [Cited S9]. FreePats deprecated GPL+exception on 2022.07.11 and said the remaining instruments
   would be relicensed [Cited S57]; no entry names the Kawai upright [Estimate: the relicensing date of this
   instrument is not documented]. Recommend the FreePats page as authoritative for the current download.
5. **Maestro Concert Grand.** Catalogue label "Custom" [Cited S22] vs `mcgreadme.txt` "All rights reserved …
   may not modify and spread" [Cited S26]: not a free licence; the kinwie remap's permission is by e-mail only
   [Cited S26].
6. **MuseScore_General size.** Handbook 35.9 MB SF3 / 208 MB SF2 [Cited S36] vs server 39,900,972 / 215,614,036
   bytes, both last modified 2020-07-10 [Cited S34]. A unit mix-up does not explain it (the server files are 38.1
   MiB and 205.6 MiB) [Estimate: arithmetic]; a different file version is the likelier cause [Estimate: neither
   page explains the figure].
7. **BBCSO Discover size** 240 MB vs 360 MB on the same page [Cited S51]; articulations per instrument not
   visible [Cited S51].
8. **VPO3 licence tension.** The site allows copying, redistribution and modification with credit, for personal
   use or free distribution, vs component licences CC BY-SA 3.0/4.0 and Sampling Plus, and Philharmonia samples
   whose owner forbids making them available as a sampler instrument [Cited S7, S33]. Share-alike, NC and
   Philharmonia parts decide: never bundled.
9. **Splendid Grand public-domain basis** rests on AKAI's 2000-era release as relayed by sfzinstruments and
   MuseScore ("confirmed via AKAI rep.") [Cited S23, S34]; no AKAI document was opened [Estimate: relayed claim only].
10. **Piano in 162 licence** not stated on the catalogue page or Ivy Audio's page [Cited S27, S28]. VCSL's "Grand
    Piano, S Model B (Joachim's Piano)" and Piano in 162 are both Steinway Model B and Ivy Audio's Simon Dalzell
    recorded for Versilian [Cited S1, S2, S27, S29]; whether they are the same instrument is unknown [Estimate: no page links the two].
11. **Sonara behaviour to test.** (a) `locc`/`hicc`-gated regions sound unconditionally [Estimate: inferred from the sfz.rs "no effect" rule, S55];
    (b) FLAC samples (Sonatina has 1,436) take the symphonia path with its `flac` feature [Cited S4, S55] but were not
    exercised with a library [Estimate: no library loaded];
    (c) Sonatina legato files become retriggered monophonic sustains [Cited S4, S55]; (d) VCSL release SFZ,
    FreePats SFZ and VPO3 files were not opened; (e) `ampeg_dynamic` in every VSCO patch checked is reported as
    ignored [Cited S1, S55].

    trumpet, cornet, flugelhorn (VG Flugelhorn is commercial, S22), Wagner tubas, cimbasso, euphonium,
    per-voice choir parts, solo voices, felt piano, prepared piano, clavinet, clavichord [Estimate: absent from

    listed here before the fact-check; Bear Sax (CC0) and MTG Solo Sax (CC BY 4.0) cover it [Cited S22, S59].
13. **GM extension notes.** 82 Shaker, 83 Jingle Bell, 84 Belltree, 85 Castanets are listed outside the GM1 range
    35-81 [Cited S54]; do not store them as GM Level 1 percussion notes.
14. **Iowa MIS redistribution** is not addressed [Cited S32]; Sonatina, VPO3 and Scarypiano redistribute
    derivatives of it [Cited S4, S7, S30]. Legal status of bundling such derivatives stays unresolved. The
    same holds, more sharply, for Philharmonia samples inside Sonatina and VPO3, since the Philharmonia's terms
