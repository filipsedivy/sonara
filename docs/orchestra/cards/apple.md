## 0. Scope and octave convention

- This file describes products and mechanisms, not acoustic instrument types, so it carries no instrument
  range cards. Pages were read in the Logic Pro for Mac 12.3 guide, the current GarageBand for Mac guide, the
  GarageBand for iPad/iPhone 2.3.x guides and four Apple press releases [Cited S1, S43, S50, S51-S54]; the
  fact-check added Apple's release notes and a fifth press release (S56-S60).
- Logic Pro names MIDI note 60 "C3" by default ("C3 (Yamaha)"), note 36 "C1" and note 0 "C-2"; the
  alternative "C4 (Roland)" setting names note 60 "C4" and note 0 "C-1" [Cited S2]. The Studio Strings and
  Studio Horns keyswitch tables say "starting from C0 (MIDI note number 24)", which is the C3 = 60 naming
  [Cited S16, S18]. Below, every pitch is given as a MIDI number first; "Apple name" uses C3 = 60 and
  "Sonara name" uses C4 = 60 [Estimate: arithmetic conversion, Apple name + 1 octave].
- The user guide's What's New stops at 12.3 [Cited S1], while Apple's release notes already list 12.4: one new
  option (Merge Custom Key Commands) and bug fixes, including fixes to Drum Machine Designer, track stacks and
  the Chord track (Sus4 chords now show all scale types); none adds an instrument feature described here
  [Cited S56].

## 1. The Library and Sound Library: categories, patches, channel strips, track stacks

| Concept | What Apple documents | Tag |
|---|---|---|
| Library window | Shows the selected track's icon, a View pop-up (all patches or one sound pack), a search field, a category list on the left and a patch list on the right, plus Options (default patch, merge), Revert, Delete and Save | [Cited S3] |
| Other file types in the Library | Channel strip settings (.cst), plug-in presets (.pst), Sampler instruments (.exs), Environment instruments and MIDI programs or banks from Audio MIDI Setup | [Cited S3] |
| Patch | Holds the instrument, effects, Smart Controls and routing settings that shape a track's sound; it can hold one or more channel strip settings, auxes and metadata for Smart Controls and controller mapping | [Cited S3] |
| Patch versus track type | The Library shows only patches compatible with the selected track type; a track has only one patch for the length of a project | [Cited S3] |
| User patches | Saving creates a User Patches folder usable in every project; built-in sounds cannot be deleted; MainStage patches appear in a subfolder | [Cited S3] |
| Choosing a patch | Selecting a patch makes it playable immediately; the left inspector channel strip then shows the patch name, the instrument plug-in and the effect plug-ins | [Cited S3] |
| Articulation Sets inside patches | "Articulation Sets are saved both within saved patches and saved projects" | [Cited S8] |
| Sound packs | Sound packs contain Apple Loops, patches, drum kits and other material; they are downloaded in the Sound Library window; some are required to open Logic Pro for iPad or GarageBand projects | [Cited S5] |
| Library bundle | All sound content (plug-in data, patches, Apple Loops, samples) lives in one `Logic Pro Library.bundle`, by default in ~/Music, relocatable; the 12.0 What's New says the content is now one package that can sit on a local, external or networked drive and be used by several users | [Cited S1, S5] |
| Performance patches | Sampler-based percussion patches with a few related instruments; a "performance key" uses velocity splits (Conga: low = Mute, moderate = Open, high = Slap); shakers and tambourines use note-on versus note-off for forward and backward movement | [Cited S4] |
| Live versus playback timing | Played live, a performance-patch sample starts at its "sample anchor"; played back from a region, the full sample plays even if it begins before the note-on | [Cited S4] |
| Folder stack | Groups tracks without changing routing; the main track is a VCA-style stack master; it has no patch and no Smart Controls | [Cited S6] |
| Summing stack | Routes subtracks to a bus whose aux is the main track; MIDI regions on the main track are played by all software-instrument subtracks; a summing-stack patch contains the main track and all subtracks with their channel strips; Logic ships patches made for summing stacks | [Cited S6] |
| Stacks and the Library | Folder-stack main track: no patches. Summing-stack main track: patches depend on the subtracks' channel strip types. Choosing a track-stack patch on a folder-stack subtrack loads the whole stack | [Cited S6] |
| GarageBand Library | Same category/patch layout; for a Drummer track the Library offers genres and drummers (Rock, Alternative, Songwriter, R&B, Electronic, Hip Hop, Percussion) | [Cited S43, S45] |
| GarageBand patch | "contains the instrument, effects, and other settings that control the sound of a track"; software-instrument patches include an instrument plug-in plus effects | [Cited S43] |

**Hierarchy (Apple's words, top to bottom).** Sound pack (download unit) → Library category → patch (one per
track; a summing-stack patch spans several tracks) → channel strip setting(s) → instrument plug-in plus
effect plug-ins, each with its own plug-in presets [Cited S3, S5, S6]. The category names of Logic Pro's
Library (for example "Orchestral > Strings") are not stated on any page read [Estimate: not found in the guide;
check in the app]. GarageBand's Smart Control page groups patches into these instrument categories: Guitar and
Bass; Drum Kits; Orchestral and Mallet; Vintage Electric Piano and Piano; Synthesizer; Vintage B3 Organ; Vintage
Clav; Vintage Mellotron [Cited S44].

### 2.1 Sampler, Quick Sampler, Alchemy

- Sampler loads "sampler instruments" (mapped collections of samples) into RAM, maps samples to key and
  velocity ranges by drag and drop, routes zones to multiple outputs, and is "fully compatible with EXS
  instrument libraries" [Cited S20]. Its panes are Synth, Mod Matrix, Modulators, Mapping and Zone; the former
  EXS "instrument" is now called a mapping and the former EXS "setting" is called synth parameters [Cited S20].
  Sampler and Quick Sampler arrived in Logic Pro 10.5, replacing the EXS24 [Cited S58, S20].
- Each Sampler group can carry an articulation ID; a note whose articulation ID matches plays only the groups
  with that ID and non-matching groups are silent [Cited S14]. A Mod Matrix routing can target "Articulation ID"
  so a controller (for example a foot pedal) switches between, say, bowed and plucked groups [Cited S14].
- Quick Sampler plays a single audio file, has Pitch, Filter and Amp panes with envelopes, two LFOs and a Mod
  Matrix; Sampler can take over a Quick Sampler setting but not the reverse [Cited S20].
- Alchemy: up to four sources (A-D), each mixing additive, spectral, granular, sampler and virtual-analog
  elements, three filters per source, two main filters, effects racks and a per-source arpeggiator; it can
  build instruments "containing hundreds of samples and layers" [Cited S21]. Logic 12.3 added a granular Sync
  mode [Cited S1].

### 2.2 Studio Strings

- "A collection of highly expressive single and section stringed instruments"; articulations are chosen in the
  plug-in header or remotely by keyswitch [Cited S15]. Introduced in Logic Pro X 10.4 together with Studio
  Horns [Cited S59].
- Main controls: Preset (solo or section), Monophonic (solo instruments), Auto Voice Split, Dynamics via CC,
  Last Played Articulation, Cutoff, Resonance, Volume, Attack, Release [Cited S15].
- Extended controls: Vibrato Controller; Dynamic Controller plus mode "Controller (Absolute)", "Velocity &
  Controller (Catch)" or "Velocity & Controller (Relative)"; Legato Transitions (for monophonic and polyphonic
  modes); Release Samples level; Pitch Bend Range up to ±12 semitones; Extended Key Range, off by default so the
  instrument "plays in the original key range" [Cited S15]. Since 10.4.5, CC 7 and CC 71-74 can be chosen as
  the Dynamic Controller [Cited S59].
- Section behaviour: with Auto Voice Split off, string sections are split by key ranges: each instrument of
  the section covers its own key range and nothing is layered [Cited S15]. With
  it on: Allow Unison (off = one player per key, so a seven-piece section needs seven keys), Split Voicing (8va,
  Drop 2, Drop 2+4), Split Mode (Start with Lead Voice, Start with Bass Voice, Start by Key Split with a Split
  Key) [Cited S15].
- Section MIDI channels (Inst via MIDI Channel on by default): channel 1 = full section; 2 = Violins 1;
  3 = Violins 2; 4 = Violas; 5 = Cellos; 6 = Double Basses [Cited S16]. The number of players per section is
  not stated on any page read [Estimate: not found].

  or minimal gap after the main note; its velocity and length may differ; live, the Fall keyswitches work in
  Trigger mode and end the held note with a fall [Cited S15].

### 2.6 Drum Kit Designer and General MIDI

- Drum Kit Designer builds kits from interchangeable pieces (Exchange pane) with per-piece Edit settings;

## 4. Smart Controls and GarageBand's touch instruments

### 4.1 Smart Controls (Logic Pro and GarageBand for Mac)

- A Smart Control is a set of screen controls; one screen control can change one or more channel strip or
  plug-in parameters; layouts are optimized per track or instrument type, and a string patch's Smart Control
  "might include controls for changing the articulation" [Cited S7, S44].
- Mapping: Learn or the Parameter Mapping menu; several mappings per screen control with the topmost one
  setting the displayed value; Range Min, Range Max, Invert Range and parameter mapping graphs; mappings are
  "saved with the patch" and can be copied between tracks with identical plug-ins [Cited S7].
- "Automatic Smart Controls" maps every screen control automatically, or only unmapped ones [Cited S7].
- Hardware: Learn assigns a controller's fader, knob, button, pad or pedal to a screen control [Cited S7].
- The Smart Controls bar adds context buttons: Arpeggiator for software instruments, Tuner for audio tracks,
  Keyswitches for instruments with articulations [Cited S7, S10].
- Summing-stack Smart Controls can map parameters on any subtrack [Cited S6].
- Smart Controls and Track Stacks both arrived with Logic Pro X in 2013 [Cited S60]; the Keyswitches view
  followed in 10.4 [Cited S59].
- GarageBand: screen-control movements made while recording are recorded and editable as automation in the
  Piano Roll; tone controls sit on the left and effects on the right in every category [Cited S44].

## 5. Performance logic: how MIDI becomes music

### 5.1 Session Players (Logic Pro 11 and 12)

- Drummer, Bass Player and Keyboard Player generate the content of "Session Player regions" on software
  instrument tracks; each region can have its own style; Bass and Keyboard Players use Studio Bass and Studio
  Piano, their Synth Player styles use Alchemy; acoustic Drummers use Drum Kit Designer and electronic ones Drum
  Machine Designer [Cited S31]. Logic 12.0 added Synth Player styles (Modulated Pad, Rhythmic Chords; Pump Bass,
  808 Bass, Sequenced Bass) [Cited S1]. The 12.0 release notes name Simple Pad in the same sentence as Modulated
  Pad and Rhythmic Chords [Cited S56]; whether Simple Pad is new in 12.0 is unclear (see open questions).
- Versions: Drummer dates from Logic Pro X 10.0 (2013) [Cited S60]; Bass Player, Keyboard Player and the
  global Chord track from Logic Pro 11.0 [Cited S57].
- Launch figures: eight Bass Players, four Keyboard Player styles, 100 Bass Player loops; Drummer "debuted as one
  of the world's first generative musicians more than a decade ago" [Cited S54].
- A new Session Player track gets one 8-bar region, or one region per arrangement marker, or the cycle or
  marquee length [Cited S31].

## 7. What this teaches Sonara

All entries in this section are [Estimate: the author's judgement, based on the cited mechanisms above].

Transferable patterns:

1. **Keep the articulation on the note, separate from how a library switches it.** Logic stores a 1-255 ID per
   note and translates it to keyswitches, CCs, program changes or MIDI channels only at the output stage of an
   Articulation Set. Sonara's `articulation_availability` already separates "the instrument plays it" from "the
   library declares it"; a per-library output map (key, CC, channel, up to three messages) is the missing
   piece, and the 15-id vocabulary should stay the note-level identity.
2. **Name the articulation, never just the number.** Apple shows bare 1-255 numbers when no set is loaded and
   silence for an unmapped ID. Sonara should resolve ids by name and warn, not go silent.
3. **Respect real ranges by default.** Studio Strings and Horns ship with Extended Key Range off. This matches
   `check_sounding` returning `BelowPlayable` or `AbovePlayable` as a warning, without clamping.
4. **Section = channel 1, players = channels 2+.** A section patch that splits chords across players (lead
   voice first, bass voice first, or by split key; unison on or off; 8va, Drop 2, Drop 2+4) is a strong model
   for "strings play the chord, violins take the melody".
5. **Express ornaments as adjacent notes.** Falls and doits are a same-pitch note directly after the main note;
   Trigger-mode keyswitches do the same live. An agent can write this without timing tricks.
6. **One harmonic source for all generators.** A global Chord track, overridable per region, followed by every
   generated part; the tonic of the key as fallback.
7. **Generators are regions with a few musical knobs.** Complexity, intensity, fills, swing, feel, humanize and
   a regenerate action, editable later and convertible to plain MIDI, give an agent a small, stable parameter set.
8. **Seeded randomness.** The Randomizer's fixed Seed makes bounces identical, which fits Sonara's deterministic
   test rule (TST-04) and golden renders (GLD-01).
9. **Patch = instrument + effects + controls + articulation map.** A Sonara preset should carry the articulation
   output map and a small labelled control set (Smart Controls), not only the sample path.
10. **Display transposition is a view.** Logic keeps MIDI at sounding pitch and transposes only in staff
    styles; Sonara's "store sounding, derive written" rule is the same design.
11. **New articulation id needed:** `scoop` = an upward slide into the note from below, used in jazz and pop
    brass, saxophone and string writing (Apple's "Scoop", "Scoop Slow", "Scoop Fast").

What not to copy:

- The C3 = 60 default note naming; Sonara stays at C4 = 60 and should label conversions explicitly.
- Apple's sign for display transposition (written minus sounding); Sonara keeps sounding minus written.
- The name "horns" for a saxophone, trumpet and trombone section; Sonara should name sections by content.
- Library-specific articulation names ("Expressive", "Passionate") as vocabulary ids; map them to a library's
  output table instead.
- Settings that live only in a GUI (Smart Control layouts, Environment objects); Sonara's equivalents must be
  reachable by the agent tools.

## Open questions and disagreements between sources

1. **Horn in Eb staff style.** Apple's table gives "Eb (−3)" [Cited S27]. A horn in Eb conventionally sounds a
   major sixth below written, which would be written minus sounding = +9, not −3; −3 has the right pitch class
   but the wrong octave [Estimate: standard orchestration practice; not verified in a handbook in this session].
   Recommendation: do not import Apple's value; verify against a handbook.
2. **Bass Player note names.** The Bass Player page says a Lowest Note of "B0 emulates five-string bass
   performances" and mentions chord tones "lower than E3" [Cited S34]. Under Logic's default naming B0 is MIDI 35
   [Estimate: derived from C1 = 36 in S2], above a four-string bass's lowest sounding E (MIDI 28 under C4 = 60) [Estimate: standard bass
   tuning]. Either the page uses another naming or Studio Bass is mapped an octave above sounding pitch. Under
   C4 = 60 naming, B0 is MIDI 23, the sounding low B of a five-string bass, which favours the first reading
   [Estimate: arithmetic; the page does not say which naming it uses]. Not resolved; check in the app before
   mapping Apple bass parts to Sonara.
3. **Scripter requirement.** The Scripter page says to "select Enable Complete Features in Logic Pro > Settings >
   Advanced" [Cited S39], while What's New for 12.0 says the Advanced pane no longer exists and all features are
   always available [Cited S1]. The guide contradicts itself; the 12.0 statement is newer and is recommended.
4. **When Studio Strings and Studio Horns appeared (resolved).** Apple's 10.4 release notes list both as new in
   Logic Pro X 10.4 [Cited S59]. See the timeline in section 0.1.
5. **Ensemble sizes.** No page read gives the number of players per Studio Strings section; only the channel
   list (Violins 1, Violins 2, Violas, Cellos, Double Basses) and the "seven piece section" example in the
   Allow Unison text [Cited S15, S16].
6. **Studio Strings keyswitch columns.** The table's second column is labelled "Violins, Violas, Cellos" and the
   first "Sections, Double Bass" [Cited S16]; whether the second column means solo instruments is not stated.
   Falls, scoops, crescendos and glissandos are marked only in the second column.
7. **Library category names** for Logic Pro and **template names** are not documented on the pages read; check
   them in the app before Sonara copies any naming [Estimate: by absence on the guide pages read; not checked in the app].
8. **"Expressive" and "Passionate"** (Studio Horns) are not defined anywhere in the guide [Cited S18 by absence];
   they need a listening test before any mapping to Sonara ids.
9. **Simple Pad.** The 12.0 release notes mention Simple Pad next to the new Synth Player styles, and the same
   notes fix bugs in "the Simple Pad style in Keyboard Session Player" [Cited S56]; the guide's 12.0 What's New
   lists only Modulated Pad and Rhythmic Chords as Keyboard Synth Player styles, and the Keyboard Player page
   treats Simple Pad as an ordinary Keyboard Player style [Cited S1, S33]. Whether Simple Pad predates 12.0 is
   not settled by the pages read.
